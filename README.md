API Dashboard — SMP Command Centre

A Python-based performance dashboard that analyzes simulated member fitness data and summarizes daily activity, step-goal achievement, and skill-enrollment statistics.

Features

Tracks member step counts, sleep hours, and fitness protocols.

Identifies members who achieve the 10,000-step goal.

Calculates average steps across members.

Counts members who report taking cold showers.

Identifies the best-performing day by total steps.

Highlights the most popular skill by enrollment.

Sample Data

The dashboard uses simulated member records and weekly activity data to demonstrate performance analysis.

Setup

Make sure Python 3 is installed.

Run the dashboard from your terminal:

python dashboard.py

Output

The program prints a formatted report in the terminal, including member performance, step-goal achievement, weekly activity, and skill-enrollment summaries.

Technology Stack

Python

JSON module

Data processing with Python lists, dictionaries, and built-in functions

Project Status

Learning project demonstrating data processing, performance metrics, and dashboard-style reporting in Python.
